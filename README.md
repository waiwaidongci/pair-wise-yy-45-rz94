# 服装品牌打样开发与版型修订工作台

为服装产品开发团队提供款式档案、样品轮次、尺寸实测、部位批注、替代改版方案、审核锁定和修订历史。

## 技术栈

React + MUI + Redux Toolkit + RTK Query + React Router + MSW + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62045`。

## 核心工作流

- 从款式档案进入开发轮次，维护尺码、面辅料、色卡和工艺要求。
- 对比两轮尺寸实测，自动高亮超出容差的部位并关联试穿意见。
- 点击样衣图片部位添加批注，或由版师提交替代方案和责任人。
- 负责人采纳方案、填写未提交草稿，审核完成后锁定轮次并保留完整历史。
